# ElectronRX - Orderan JOKI WEBSITE

**ElectronRX** adalah aplikasi web sederhana yang berfungsi sebagai toko elektronik online. Proyek ini memungkinkan pengguna untuk mengelola produk elektronik dengan menggunakan fitur CRUD (Create, Read, Update, Delete) dan menampilkan statistik penjualan atau produk melalui grafik. 

Aplikasi ini dirancang untuk memberikan kemudahan bagi pengelola toko dalam mengatur daftar produk dan memantau statistik terkait produk yang dijual.

## Fitur Utama

- **CRUD Produk**: Fitur lengkap untuk menambah, melihat, memperbarui, dan menghapus produk elektronik.
- **Statistik Chart**: Menyediakan visualisasi statistik penjualan atau jumlah produk melalui grafik untuk membantu pengelolaan toko.
- **Desain Responsif**: Menggunakan **Bootstrap 5** untuk memastikan tampilan yang responsif, sehingga nyaman digunakan di perangkat desktop maupun mobile.
- **Pengelolaan Produk**: Menyediakan antarmuka pengguna yang mudah digunakan untuk mengelola data produk elektronik dengan efisien.

## Teknologi yang Digunakan

- **CodeIgniter 4**: Framework PHP modern yang digunakan untuk membangun aplikasi web ini dengan performa tinggi dan arsitektur yang terstruktur.
- **Bootstrap 5**: Framework CSS yang digunakan untuk mendesain antarmuka pengguna responsif yang elegan dan user-friendly.
- **MySQL**: Sistem manajemen basis data untuk menyimpan informasi produk dan transaksi.
